Política de Privacidad

Esta Política de Privacidad explica cómo Rubricando para Moodle trata los datos cuando los usuarios importan rúbricas de Moodle desde archivos CSV o Excel y, cuando existan, utilizan funciones asistidas por IA.

Quiénes somos

Rubricando para Moodle es una extensión de Chrome diseñada para ayudar a importar criterios, descripciones de nivel y puntuaciones a páginas de edición de rúbricas de Moodle desde archivos CSV o Excel.

Qué datos trata la extensión

La extensión puede tratar las siguientes categorías de datos:

  • Archivos CSV o Excel seleccionados o soltados explícitamente por el usuario.
  • Contenido relacionado con rúbricas ya presente en páginas compatibles de edición de rúbricas de Moodle.
  • Acciones del usuario necesarias para realizar la importación, como seleccionar un archivo o iniciarla.
  • Datos técnicos de solicitud necesarios para completar llamadas opcionales a APIs remotas de IA, si esas funciones están habilitadas.

Cómo usa la extensión los datos

  • Para interpretar el contenido CSV o Excel y extraer criterios, niveles y puntuaciones.
  • Para insertar la interfaz de importación en páginas compatibles de edición de rúbricas de Moodle.
  • Para completar el formulario de la rúbrica de Moodle con los datos proporcionados por el usuario.
  • Para dar soporte a funciones opcionales asistidas por IA, si existen y el usuario las utiliza.

Procesamiento con IA

La extensión puede incluir funciones asistidas por IA en algunas versiones. Cuando esas funciones estén disponibles, los datos podrán procesarse de una de estas dos formas, según la función y la configuración:

  • Localmente en el dispositivo del usuario mediante un modelo en local.
  • De forma remota a través de un proveedor externo de API de IA utilizado para completar la función solicitada.

Cuando se utilice procesamiento remoto con IA, solo debería transmitirse el contenido razonablemente necesario para ejecutar la función solicitada por el usuario. Esto puede incluir fragmentos del archivo CSV o Excel seleccionado, texto de la rúbrica en la página de Moodle y prompts o instrucciones del usuario. Si se usa un proveedor remoto, ese proveedor podrá tratar los datos enviados conforme a sus propios términos y política de privacidad.

Compartición de datos

No vendemos datos de usuario. No compartimos datos de usuario con terceros salvo en estos casos:

  • Cuando el usuario utiliza explícitamente una función asistida por IA que depende de un proveedor remoto de API.
  • Cuando la divulgación es exigida por ley, regulación o proceso legal.
  • Cuando compartir la información es técnicamente necesario para prestar la función solicitada a través de la infraestructura de red.

Código remoto

La extensión no descarga ni ejecuta código remoto JavaScript o WebAssembly como parte de su funcionamiento principal.

Conservación de datos

La extensión está diseñada para procesar las importaciones localmente en el navegador siempre que sea posible. No operamos una base de datos backend para almacenar archivos de rúbricas importados ni contenido de páginas Moodle. Si se utiliza una API remota opcional de IA, los datos transmitidos podrán ser conservados por el proveedor correspondiente según su propia política.

Seguridad

Procuramos minimizar el acceso a datos a lo estrictamente necesario para la finalidad única de la extensión. Cuando existan solicitudes a APIs remotas, deberían transmitirse por canales seguros como HTTPS.

Opciones del usuario

  • Los usuarios eligen qué archivo CSV o Excel importar.
  • Los usuarios pueden dejar de usar la extensión en cualquier momento desinstalándola.
  • Los usuarios pueden evitar el procesamiento remoto con IA no utilizando funciones asistidas por IA que dependan de APIs externas.

Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando cambie la extensión, incluyendo el caso de que se introduzcan nuevas funciones asistidas por IA o nuevas integraciones. La última versión publicada de esta página es la que resulta aplicable.

Contacto

Para consultas de privacidad o soporte, utiliza el contacto o la URL de soporte indicada en la ficha de Chrome Web Store de Rubricando para Moodle.
